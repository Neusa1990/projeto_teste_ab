# Análise de Teste A/B: Otimização de Loja Online

Este projeto foca na priorização de hipóteses e análise de resultados de um teste A/B para aumentar a receita.

## 📈 Principais Conclusões
- **Vencedor**: Grupo B.
- **Conversão**: Aumento estatisticamente significativo de **19.8%**.
- **Ticket Médio**: Não houve alteração significativa, indicando que o ganho vem do volume de novos compradores.

## 🛠️ Tecnologias
- Python, Pandas, Matplotlib, Scipy.
